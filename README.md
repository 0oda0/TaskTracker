Веб-таск-трекер для 2+ человек: разовые/повторяющиеся задачи по сферам (работа, физ. нагрузка, рутина, личное),
взаимная видимость прогресса, передача задач другому человеку с его согласия, общий и личные списки покупок.

Стек: Node.js (Express + EJS) + встроенный `node:sqlite` (без внешней БД и без ORM). Требует Node ≥ 22.5.
Сессии — подписанная cookie (`cookie-session`), без серверного стора.

## Локальный запуск

```bash
npm install
SESSION_SECRET=dev node server.js
```

Открыть http://localhost:3000, зарегистрировать аккаунты (минимум 2, чтобы задачи можно было раздавать друг другу).

## Тесты

```bash
npm test
```

## Деплой на сервер (Docker)

```bash
cp .env.example .env   # и вписать реальный SESSION_SECRET
docker compose up -d --build
```

Приложение слушает порт 3000 (см. `docker-compose.yml`), данные SQLite живут в volume `db-data` —
переживают пересборку контейнера. Поставьте перед ним reverse-proxy (Caddy/nginx) для HTTPS и домена;
после этого включите `COOKIE_SECURE=true` в `.env` и пересоздайте контейнер.

## Модель

- **Сферы**: фиксированный список (Работа/учёба, Физ. нагрузка, Рутина, Личное) — задачи привязаны к сфере.
- **Периодичность задачи**: `once` (разово, с датой) / `daily` / `weekly` (опционально день недели) / `monthly` (опционально число месяца).
- **Цель за период**: у задачи можно задать число (например 100) — тогда прогресс считается количеством («75/100»), а не просто готово/не готово; отмечать выполнение можно частями.
- **Стрик и история**: на карточке задачи и на странице «Прогресс» — текущая серия подряд закрытых периодов (🔥) и точки истории за последние периоды.
- **Прогресс**: у каждого пользователя — отдельная плитка на каждую активную задачу, сгруппированные по сфере, видны всем.
- **Редактирование**: автор задачи может менять название/описание/сферу/периодичность/цель (исполнителя — только через передачу с согласием).
- **Передача задачи**: исполнитель может предложить задачу другому, либо любой пользователь — запросить задачу у текущего исполнителя; применяется только после согласия второй стороны (раздел «Передачи»).
- **Долг за неделю**: для ежедневных задач с целью (`daily` + цель) итог недели (Пн–Вс) подводится в воскресенье в 18:01 по времени сервера — если накопленный недобор > 0, создаётся отдельная разовая задача-долг на именно эту нехватку плюс уведомление (раздел 🔔). Проверка идёт раз в минуту и наверстывает пропуски после простоя сервера — см. `src/debt.js`.
- **Покупки**: один общий список (виден всем) + личные списки на пользователя.

### Известные упрощения

- Дедлайн долга (вс 18:01) и "сегодня" везде — время сервера, без часовых поясов на пользователя.
- `isQualifyingDay` в `src/debt-calc.js` сравнивает дату создания задачи (UTC) с локальными датами недели — минимальная погрешность возможна около полуночи.
- Уведомления только внутри приложения (страница 🔔), без email/push.
