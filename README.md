Веб-таск-трекер для друзей/семьи: разовые/повторяющиеся задачи по сферам, цели с числовым прогрессом,
стрики, передача задач с согласием, недельный «долг» за невыполненное, чат, общие и личные списки покупок.

Стек: Node.js (Express + EJS) + встроенный `node:sqlite` (без внешней БД и без ORM). Требует Node ≥ 22.5.
Сессии — подписанная cookie (`cookie-session`), без серверного стора; смена пароля инвалидирует остальные сессии
(`session_version`, проверяется в `src/auth-mw.js`).

## Локальный запуск

```bash
npm install
SESSION_SECRET=dev node server.js
```

Открыть http://localhost:3000, зарегистрировать аккаунты (минимум 2 — первый зарегистрированный автоматически
становится администратором, `/admin`).

## Тесты

## Деплой на сервер (Docker)

```bash
cp .env.example .env   # и вписать реальный SESSION_SECRET
docker compose up -d --build
```

Приложение слушает порт 3000 (см. `docker-compose.yml`), данные SQLite живут в volume `db-data` —
переживают пересборку контейнера. Схема мигрируется на лету (`ALTER TABLE`, см. `src/db.js`) — обновление
кода не требует пересоздания БД. Поставьте перед ним reverse-proxy (Caddy/nginx) для HTTPS и домена; после
этого включите `COOKIE_SECURE=true` в `.env` — без HTTPS не заработает и установка как PWA (см. ниже).

Бэкапы: `scripts/backup-db.sh` (консистентный снапшот через `VACUUM INTO`, хранит 14 дней) — повесить в cron
на хосте, например `30 3 * * * /opt/tasktracker/scripts/backup-db.sh >> /var/log/tasktracker-backup.log 2>&1`.

## Модель

- **Друзья**: добавление по короткому коду (не по логину — у каждого свой код, страница «Друзья»). Видимость
  задач/прогресса/общих списков покупок ограничена собой + принятыми друзьями. Отдельно от дружбы — разрешение
  «назначать мне задачи» (каждый выдаёт его конкретным друзьям сам, по умолчанию выключено) и личный тег
  («жена», «друг»...), оба хранятся как собственная настройка каждого пользователя про конкретного друга.
- **Сферы**: фиксированный список (Работа/учёба, Физ. нагрузка, Рутина, Личное).
- **Периодичность задачи**: `once` (разово, с датой) / `daily` / `weekly` (опц. день недели) / `monthly` (опц. число месяца).
- **Цель за период**: у задачи можно задать число (например 100) — прогресс считается количеством («75/100»),
  выполнение можно логировать частями. Выполненная разовая задача архивируется автоматически.
- **Стрик и история**: текущая серия подряд закрытых периодов (🔥) и точки истории на карточке задачи и на «Прогрессе».
- **Передача задачи**: исполнитель может предложить задачу другу, либо друг — запросить задачу у исполнителя;
  применяется только после согласия второй стороны.
- **Долг за неделю**: для ежедневных задач с целью — итог недели (Пн–Вс) подводится в воскресенье в 18:01 по
  времени сервера; недобор становится отдельной задачей-долгом плюс уведомление. См. `src/debt.js`.
- **Чат**: личные сообщения между друзьями (`/chat/:friendId`) и отдельный тред с поддержкой (`/support` →
  `/admin/support`); новое сообщение — уведомление.
- **Покупки**: общий список видим только создателю и его друзьям (не всем зарегистрированным), плюс личные списки.
- **Профиль**: имя, цвет аватара, смена пароля, код друга (можно перегенерировать), светлая/тёмная тема,
  удаление аккаунта.
- **Админка** (`/admin`, первый зарегистрированный — автоматически админ): список/карточка пользователя, смена
  роли (с защитой последнего админа), сброс пароля пользователю (единственный путь для забывшего пароль — email
  не используется), удаление аккаунта, входящие обращения в поддержку, DAU/WAU/MAU и график регистраций.
- **PWA**: манифест + иконки + минимальный service worker, кнопка «Установить» показывается, когда браузер
  реально предлагает установку. **Требует HTTPS** — на голом HTTP не сработает.
- **Rate limit на вход**: 8 неудачных попыток за 15 минут блокируют и по IP, и по логину (`src/rate-limit.js`).

### Известные упрощения

- Дедлайн долга (вс 18:01) и «сегодня» везде — время сервера, без часовых поясов на пользователя.
- `isQualifyingDay` в `src/debt-calc.js` сравнивает дату создания задачи (UTC) с локальными датами недели —
  минимальная погрешность возможна около полуночи.
- Уведомления только внутри приложения (страница 🔔), без email/push — Web Push потребовал бы HTTPS и VAPID-ключи,
  пока не сделано.
- Аватар — только цвет + инициал, без загрузки изображения.
